# 03. 데이터 조사·정의서

## 1. 데이터 소스 요약

| 항목 | 일별 시세 | 연도별 재무 | 종목 마스터 |
|---|---|---|---|
| 데이터 출처 | FinanceDataReader (KRX 시세) | OpenDART `fnlttSinglAcnt` (사업보고서 `11011`) | 팀이 작성한 `backend/data/companies.csv` |
| 데이터 유형 | Python 라이브러리 (CSV로 대체 가능) | Open API (JSON) | CSV |
| 원본 컬럼 | Open, High, Low, Close, Volume, Change | account_nm, thstrm_amount, fs_div ... | code, name, market, sector |
| 필요한 컬럼 | Open, High, Low, Close, Volume | 매출액, 영업이익, 당기순이익, 자산총계, 부채총계, 자본총계 | 전체 |
| 수집 방법 | `scripts/collect_prices.py` | `scripts/collect_dart.py` | `scripts/load_master.py` |

| 전처리 | 아래 참고 | 연결(CFS) 우선, 없으면 개별(OFS), 금액 문자열 → 정수 | 공백 제거 |

## 2. 알아 둘 제약 (조사 결과)
- **KRX 인증 변경**: 한국거래소가 로그인 후에만 조회되도록 바뀌어, `pykrx` 가 비인증 요청에서 400 오류를 내는 사례가 보고되었다. FinanceDataReader 0.9.110 은 GitHub 캐시를 이용해 로그인 없이 쓰도록 대응했다. → 이 프로젝트는 FinanceDataReader 를 쓰고, 막힐 때를 대비해 **CSV 적재 경로(`--csv-dir`)** 를 함께 둔다.
- **OpenDART**: 인증키가 필요하고 일일 호출 한도가 있다(한도 값은 계정/시점에 따라 달라 발급 후 확인). 종목당 연도별로 1회씩 호출한다.
- 전체 재무제표(fnlttSinglAcndAll) 는 2015 사업연도부터 제공된다. 이 프로젝트는 주요계정(`fnlttSinglAcnt`)만 쓴다.
- 최근에 상장한 종목(예: 2022년 상장)은 이전 연도 재무가 없다. → 해당 연도는 건너뛴다(경고 로그).

## 3. 컬럼 정의 — 일별 시세 (`daily_prices`)

| 컬럼 | 데이터형 | 설명 |
|---|---|---|
| price_id | BIGSERIAL | 시세 ID (PK) |
| company_id | INT | 종목 ID (FK) |
| trade_date | DATE | 거래일 |
| open_price | INT | 시가 (원) |
| high_price | INT | 고가 (원) |
| low_price | INT | 저가 (원) |
| close_price | INT | 종가 (원) |
| volume | BIGINT | 거래량 (주) |

등락률은 종가에서 계산할 수 있는 값이라 **저장하지 않고** 뷰(`v_price_change`)로 계산한다. (→ 05번 문서)

## 5. 전처리 규칙 (시세) — `collect_prices.clean()`

| 순서 | 처리 | 이유 |
|---|---|---|
| 1 | Open/High/Low/Close/Volume 컬럼만 사용 | 필요한 컬럼만 저장 |
| 2 | 결측치 행 제거 | 가격이 없는 행은 시세로 볼 수 없음 |
| 3 | 거래량 0 인 행 제거 | 거래정지·휴장일 |
| 4 | 가격이 0 이하인 행 제거 | 이상값 |
| 5 | 고가 < 저가 인 행 제거 | DB CHECK 제약 위반 방지, 데이터 오류 |
| 6 | 소수 가격을 정수(원)로 변환 | 컬럼 타입 INT |
| 7 | 같은 날짜 중복 시 마지막 값 유지 | UNIQUE (company_id, trade_date) |

적재는 `INSERT ... ON CONFLICT DO UPDATE` 로 하므로 여러 번 실행해도 중복되지 않는다.
