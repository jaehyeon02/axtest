# 01. 프로젝트 기획서

## 1. 프로젝트명
**주식 종목 데이터 서비스 — 주가·재무 데이터를 DB로 구축하고 조회·관리·통계를 제공하는 API**

## 2. 프로젝트 배경
- 주가와 재무 정보는 제공처마다 형식이 달라서, 여러 종목을 같은 기준으로 비교하려면 매번 데이터를 직접 모아 정리해야 한다.
- 주가는 매일 쌓이는 시계열 데이터라 구조화하지 않으면 "한 달 평균", "업종별 비교" 같은 질문에 바로 답하기 어렵다.

## 3. 문제 정의
> 종목별 주가와 재무 데이터는 흩어져 있고 형식이 달라, 일반 사용자가 기간별·업종별로 비교하기 어렵다.

## 4. 프로젝트 목적
> 실제 주가(FinanceDataReader)와 재무(OpenDART) 데이터를 수집·가공하여 관계형 데이터베이스(PostgreSQL)로 구축하고, FastAPI로 데이터를 등록·조회·수정·삭제하며 SQL 기반 통계(월별 추이, 업종별 비교, 등락률 순위, 재무 비율)를 제공한다.

## 5. 대상 사용자
- 여러 종목의 가격 흐름과 재무 지표를 한곳에서 비교하고 싶은 개인 투자 입문자
- (서비스 관점) 이 API를 호출해 화면을 만들 후속 프론트엔드 개발자

## 6. 주요 기능
| 구분 | 기능 |
|---|---|
| 데이터 구축 | 종목 마스터 적재, 일별 시세 수집·전처리·적재, 연도별 재무 적재 |
| 조회·관리 (CRUD) | 종목, 일별 시세, 종목 메모의 등록·조회·수정·삭제 |
| 통계 (SQL) | 종목 요약, 월별 통계, 업종별 평균 등락률, 등락률/거래량 TOP N, 변동성 큰 종목, 재무 비율 |

## 7. 활용 데이터
| 데이터 | 출처 | 형태 |
|---|---|---|
| 일별 시세(시가·고가·저가·종가·거래량) | FinanceDataReader | Python 라이브러리 / CSV 대체 가능 |
| 연도별 재무(매출·영업이익·순이익·자산·부채·자본) | OpenDART (금융감독원 전자공시) | Open API |
| 종목 마스터(종목코드·이름·시장·업종) | 팀이 작성한 CSV | CSV |

## 8. 기대 효과
- 실제 데이터를 정규화된 구조로 저장하는 경험(ERD → DDL → 적재)
- JOIN / GROUP BY / HAVING 으로 의미 있는 통계를 직접 만들어 보는 경험
- FastAPI → SQLAlchemy → PostgreSQL 요청 흐름을 설명할 수 있게 됨

## 9. 개발 환경
Python 3.10+, PostgreSQL 16 (Docker), FastAPI, SQLAlchemy, Pandas, Swagger UI(`/docs`)
