# 02. 요구사항 정의서

이 문서는 **기능의 범위를 정하는 문서**다. "필수"만 구현하면 프로젝트는 완료이고, "선택"은 시간이 남을 때만 한다.

## 기능 요구사항

| ID | 요구사항 | CRUD | 중요도 | 대응 API |
|---|---|:---:|:---:|---|
| REQ-01 | 시장·업종 목록을 조회할 수 있다 | R | 필수 | `GET /markets`, `GET /sectors` |
| REQ-02 | 업종을 등록할 수 있다 | C | 선택 | `POST /sectors` |
| REQ-03 | 종목을 이름/시장/업종으로 검색·조회할 수 있다 | R | 필수 | `GET /companies`, `GET /companies/{id}` |
| REQ-04 | 종목을 등록할 수 있다 | C | 필수 | `POST /companies` |
| REQ-05 | 종목 정보를 수정할 수 있다 | U | 필수 | `PUT /companies/{id}` |
| REQ-06 | 종목을 삭제할 수 있다 (시세·재무·메모 함께 삭제) | D | 필수 | `DELETE /companies/{id}` |
| REQ-07 | 종목·기간별 일별 시세를 조회할 수 있다 | R | 필수 | `GET /prices`, `GET /prices/{id}` |
| REQ-08 | 일별 시세를 등록할 수 있다 | C | 필수 | `POST /prices` |
| REQ-09 | 일별 시세를 수정할 수 있다 | U | 필수 | `PUT /prices/{id}` |
| REQ-10 | 일별 시세를 삭제할 수 있다 | D | 필수 | `DELETE /prices/{id}` |
| REQ-11 | 연도별 재무 정보를 조회할 수 있다 | R | 필수 | `GET /financials` |
| REQ-12 | 종목 메모를 등록·조회·수정·삭제할 수 있다 | CRUD | 필수 | `/notes` |
| REQ-13 | 종목별 요약 통계(거래일수, 평균/최고/최저 종가, 평균 거래량)를 조회할 수 있다 | R | 필수 | `GET /statistics/summary` |
| REQ-14 | 월별 통계(평균 종가, 최고/최저가, 거래량 합계)를 조회할 수 있다 | R | 필수 | `GET /statistics/monthly` |
| REQ-15 | 업종별 평균 등락률을 조회할 수 있다 | R | 필수 | `GET /statistics/sectors` |
| REQ-16 | 특정 일자의 등락률/거래량 TOP N 을 조회할 수 있다 | R | 필수 | `GET /statistics/ranking` |
| REQ-17 | 변동성이 큰 종목(±N% 이상 움직인 날이 M일 이상)을 조회할 수 있다 | R | 선택 | `GET /statistics/volatile` |
| REQ-18 | 재무 비율(영업이익률, 부채비율, ROE)을 조회할 수 있다 | R | 선택 | `GET /statistics/financial-ratios` |

## 데이터 요구사항
| ID | 요구사항 |
|---|---|
| DATA-01 | 실제 데이터를 사용한다 (시세: FinanceDataReader, 재무: OpenDART) |
| DATA-02 | 같은 종목·같은 날짜의 시세는 한 건만 저장된다 (UNIQUE) |
| DATA-03 | 수집 스크립트를 여러 번 실행해도 데이터가 중복되지 않는다 |
| DATA-04 | 고가 ≥ 저가, 가격·거래량 ≥ 0 을 DB 제약조건으로 보장한다 |

## 비기능 요구사항
| ID | 요구사항 |
|---|---|
| NFR-01 | 잘못된 입력은 422, 없는 데이터는 404, 중복은 409 로 응답한다 |
| NFR-02 | 요청과 오류는 로그로 남긴다 |
| NFR-03 | Swagger(`/docs`)에서 모든 API 를 실행해 볼 수 있다 |

## 제외 범위
로그인/권한, 화면(React), AI 분석(LLM·RAG), 실시간 시세, 매매 기능
