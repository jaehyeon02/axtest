# 07. 테스트 결과서

## 테스트 방법
1. **자동 테스트**: `cd backend && pytest -v` (DB 가 떠 있어야 함). 테스트용 종목 `999999` 를 만들고 끝나면 삭제한다.
2. **수동 테스트**: Swagger UI(`/docs`)에서 직접 실행해 응답과 상태코드를 확인한다.

각 기능은 **정상 데이터 / 잘못된 데이터 / 존재하지 않는 ID / 빈 데이터** 네 가지 경우를 본다.

> **작성 안내:** `결과` 칸은 팀이 직접 실행한 뒤 PASS / FAIL 로 채운다. FAIL 이면 `비고`에 원인과 조치를 적는다.
> 자동 테스트 함수명은 `backend/tests/test_api.py` 의 함수와 같다.
